## 🔮 Featured Project: Vaani

<div align="center">
  <img src="https://play-lh.googleusercontent.com/7MoayL3utKLYkohL0aKR2pA0uc4Y3NRCeRBDS8W3veyTwUbRLtyd-Vi-9hYzGLlcPr-jlPtuYcmTEj8Hv29I=w832-h470-rw" alt="Vaani Preview" width="600" style="border-radius: 12px; box-shadow: 0 8px 16px rgba(0,0,0,0.3);" />
</div>

<br/>

**Vaani** is a privacy-first, fully offline AI chat application for Android. It operates with **zero servers** and **zero data collection**, running inference entirely on-device.

- **Stack:** `Expo SDK 56` | `llama.rn` | `Zustand` | `Clean Architecture` | `Reanimated + SVG`
- **Key Features:**
  - 🎙️ **Offline voice input & TTS:** Integrated Text-To-Speech with buffered token streaming.
  - ⚡ **Arm64-v8a optimization:** Extremely fast local LLM inference optimizations.
  - ✨ **Custom Animations:** Micro-animations (e.g., dynamic "breathing orb") built with Reanimated & SVG.
  - ⚙️ **Seamless Parity:** EAS ↔ Local build parity via custom Expo config plugins.
